# Houdata Brand UI

Use this skill whenever an artifact must look and behave like Houdata. Read `references/tokens.json` before choosing colors, typography, spacing, or component states.

## Workflow

1. Identify the target surface: product console, document, or presentation.
2. Apply the shared tokens while adapting density and layout to that surface.
3. Prefer live text for `houdata.` in product surfaces. Use the approved symbol asset for the mark.
4. Validate both light and dark variants when the surface supports them.
5. Check contrast, focus states, loading/error states, and responsive behavior.

## Core rules

- Use lowercase `houdata`.
- The official lockup is `[symbol] houdata.`; the final period is accent teal.
- Teal means active, connected, optimized, selected, or intelligent action. Do not use it as generic decoration.
- Keep the visual tone audacious, clear, elegant, and enterprise-ready.
- Avoid generic AI, cloud, circuit, database-cylinder, and cyberpunk visual clichés.
- Keep the symbol geometry unchanged when using the approved asset.

## Surface guidance

### Product console

Use dark mode as a first-class option, with dense but calm layouts, strong table hierarchy, and teal reserved for active paths and optimized states. Provide a light mode with the same semantic tokens.

### Documents and presentations

Use the lockup sparingly with generous clear space. Prefer warm white pages and deep navy title pages; keep charts restrained and use teal only to highlight the key conclusion.

For document creation, migration, templates, or layout QA, also use `houdata-documents`. It owns the native Google Docs cover, header, reading-column, list-preservation, and verification contract.

## Validation checklist

- Correct lowercase wordmark and accent period.
- Approved symbol used without geometric alterations.
- Light and dark contrast checked.
- Accent teal used semantically.
- Typography remains legible at the intended size.
- Empty, loading, error, success, hit, miss, and invalidated states are distinguishable.
