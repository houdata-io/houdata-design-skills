# Packaged resources

This skill is self-contained in this release package. Its local resources are:

- `references/tokens.json`: Houdata color, typography, and semantic tokens.
- `assets/houdata-mark.svg`: approved scalable Houdata symbol.
- `assets/fonts/InterVariable.ttf` and `assets/fonts/OFL.txt`: Inter variable font and its license.
- `assets/icons/`: Houdata semantic SVG icon family and provenance notes.
