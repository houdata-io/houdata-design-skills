# Houdata Design Skills

This repository is the curated distribution surface for Houdata design skills. The canonical editable sources remain in the Houdata design repository. Each skill carries the brand tokens and assets it needs; see its `references/packaged-resources.md`.

The package follows the portable plugin layout: `plugin.json` at the root and skills under `skills/`. A repo-scoped marketplace manifest is included at `.agents/plugins/marketplace.json`. Add the public source to Codex with `codex plugin marketplace add houdata-io/houdata-design-skills`, then install `houdata-design-skills` from that marketplace. Original skill text and diagram icons are CC BY 4.0; Houdata marks are excluded and Inter is under OFL. See `LICENSE.md` and `NOTICE.md`. Bulma and Google Docs access are capabilities of the user's development environment and are not bundled.

Manifest version `0.1.0` is provisional; no tagged release has been made. Review `PUBLICATION_CHECKLIST.md` before a team-wide rollout.
